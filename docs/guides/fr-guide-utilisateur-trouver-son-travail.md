# Guide utilisateur — où trouver mon travail

Après connexion, l’accueil est **Mon travail** (`/overview`), sauf pour un contact fournisseur (portail messages).

## Par rôle

| Rôle | Où regarder en premier | Recherche par référence |
|---|---|---|
| Demandeur (Sami) | **Mon travail** → « Demandes que j’ai créées » ; **Demandes d’achat** | Champ recherche (référence / titre) |
| Approbateur (Karim) | **Mon travail** → « En attente de mon action » ; **Approbations** | Recherche dans Approvals |
| Responsable achats (Mehdi) | **Boîte d’achats** ; badge de navigation | Recherche file d’achats |
| Acheteur (Ines) | **Mon travail** / **Boîte d’achats** (assignées) ; dossier | Idem + Logistique |
| Logistique | **Logistique** (commandes confirmées) | Référence demande / commande / envoi |
| Réceptionnaire (Omar) | Dossier en **Livré** via recherche demande ; actions réception sur le dossier | Recherche Demandes (périmètre autorisé) |
| Fournisseur | **Portail fournisseur** | Conversations autorisées uniquement |

## Soumission et référence

1. Soumettez la demande → dialogue **Demande soumise** avec **Référence de la demande**.
2. **Copier la référence** ou **Ouvrir la demande**.
3. Sur le dossier, la référence reste visible et copiable.
4. Les brouillons affichent un libellé brouillon — **pas de numéro définitif avant soumission**.

## Trouver le dossier d’un collègue

1. Demandez la **référence de la demande** (pas l’identifiant technique).
2. Collez-la dans la recherche de la liste pertinente (espaces avant/après ignorés).
3. Si rien n’apparaît : soit hors périmètre société/rôle (aucun indice d’existence), soit mauvaise référence.

## Suite du parcours (rappel)

Approbation → file achats → assignation / acceptation → RFQ / devis → adjudication → commande → confirmation → **Logistique** → livraison → réception → facture / clôture. La clôture et le statut de paiement restent **distincts**.
